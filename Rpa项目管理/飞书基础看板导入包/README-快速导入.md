# 飞书基础看板导入包（六大场景）

## 文件清单
- `01_场景主表.csv`
- `02_关键里程碑表.csv`
- `03_任务明细表.csv`
- `04_风险问题表.csv`
- `05_AI看板提示词.txt`

## 导入顺序
1. 新建飞书多维表格（建议名称：`RPA六大场景看板`）
2. 依次导入以上 4 个 CSV（每个 CSV 一张表）
3. 将以下字段改为“关联记录”，关联到 `01_场景主表`
   - `02_关键里程碑表.场景ID`
   - `03_任务明细表.场景ID`
   - `04_风险问题表.场景ID`

## 关键字段类型建议
- 日期：计划开始日期、计划完成日期、截止日期、实际完成日期
- 数字：总体进度%、完成度%、逾期天数
- 单选：当前阶段、状态、优先级、风险等级
- 人员：负责人

## 看板必备卡片（AI可直接生成）
- 六大场景进度总览（按场景）
- 关键里程碑（本月/下月）
- 逾期任务数（总数+按场景）
- 开放风险数（高/中/低）
- 本周完成与下周计划
