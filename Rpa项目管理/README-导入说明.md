# 飞书多维表格导入包（RPA项目管理）

## 文件清单
- `01_项目主表.csv`
- `02_里程碑任务表.csv`
- `03_风险问题表.csv`
- `04_文档资产台账.csv`
- `05_周报填报模板.csv`
- `06_AI助手提示词.txt`

## 导入顺序（建议）
1. 先新建一个多维表格（例如：`RPA项目管理台账`）。
2. 依次导入上述 CSV 文件，每个 CSV 对应一张数据表。
3. 先导 `01_项目主表.csv`，再导其余表，方便后续做关联字段。

## 字段类型建议
- 单行文本：编号、名称、路径、备注
- 单选：阶段、状态、风险等级、风险类型
- 人员：项目经理、负责人
- 日期：计划/实际完成、截止日期
- 数字：完成度、运行次数、成功次数、失败次数
- 多行文本：本周进展、问题描述、应对策略

## 推荐视图
- 项目总览（按状态分组）
- 本周待办（筛选：任务状态=未开始/进行中，截止日期<=本周日）
- 高风险清单（筛选：风险等级=高，状态!=已关闭）
- 已交付项目（筛选：项目状态=已交付）
- 月报数据视图（按月份分组）

## 自动化建议（飞书自动化）
- 到期前2天且任务未完成 -> 通知负责人
- 风险等级=高且状态=开放 -> 通知项目经理
- 项目状态=阻塞且持续>3天 -> 通知管理群
- 每周五16:00 -> 自动提醒填写周报模板
