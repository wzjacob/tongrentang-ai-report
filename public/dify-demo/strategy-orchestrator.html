问策智能体：集团级策略编排 Demo

融合问药（知识语义）+ 问数（经营数据）双输入，生成区域策略建议并追踪执行状态。

输入层 数据融合输入

  • 问药侧：品种功效、适应症、竞品替代关系、患者问答高频标签
  • 问数侧：区域动销、毛利贡献、终端覆盖、活动转化与库存周转
  • 外部侧：行业政策变化、价格带波动、渠道反馈与舆情趋势
流程：采集 -> 统一口径 -> 规则校验 -> 策略计算

执行层 CLINE 策略 Agent

  • 自动识别“人/货/场”偏差并输出可执行动作（调价、铺货、促销、培训）
  • 按单位自动生成《区域经营建议单》并推送到责任部门
  • 对策略执行结果进行回写评估，形成下轮优化建议
流程：识别机会点 -> 生成建议 -> 分派执行 -> 复盘迭代

输出层 周度经营看板（示例）

+12.6%重点品种动销提升
-18.3%低效促销投入
+9.4%区域策略执行率
建议结论：先攻“高潜低渗透”区域，优先匹配门店培训与结构化促销动作；控制库存风险，避免促销后回落。
